# TILT SIMULATOR

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/events-prototype/tilt-simulator/)

## Description

> Three League of Legends post-game phrases fall down the screen at once. Click to start, then type each one before it reaches the bottom or get one wrong and it's game over, type all 20 and you win. Started out as a generic typing-game clone and accidentally turned into a League tilt simulator instead.
>
> Built around events: `mousePressed()` starts and restarts the game, and `keyTyped()` checks every character you type against each falling phrase.
