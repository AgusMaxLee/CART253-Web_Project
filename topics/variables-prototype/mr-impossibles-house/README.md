# MR. IMPOSSIBLE'S HOUSE

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/variables-prototype/mr-impossibles-house/)

## Description

> This combines the ideas from two earlier, standalone prototypes (Mr. Impossible and Swinging Door) into one small, functioning "game": a house made of two walls and five doors.
>
> 1. **Character** — click anywhere in the house and Mr. Impossible eases toward that point over time.
> 2. **Doors** — each door's "openness" is continuously calculated from how close Mr. Impossible currently is to it (using `dist()` and `map()`), so doors swing open as he approaches and shut again as he walks away.
> 3. **Walls** — the walls are solid everywhere except at an actual doorway gap, so Mr. Impossible can only pass from one side of the house to the other by walking through an open door.
>
> Click anywhere to move Mr. Impossible around the house.
