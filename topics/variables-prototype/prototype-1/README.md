# MR. IMPOSSIBLE

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/variables-prototype/prototype-1/)

## Description

> Mr. Impossible is a little square character who eases toward wherever you click, instead of teleporting there instantly. Two small eyes on his face always look in the direction he's currently heading, and he's constrained so he can never leave the canvas.
