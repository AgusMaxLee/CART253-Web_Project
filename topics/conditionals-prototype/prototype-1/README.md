# MYSTERY GIFT

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/conditionals-prototype/prototype-1/)

## Description

> Click the gift box and a conditional picks one of 5 random outcomes to reveal: a puppy, socks, a million dollars, an empty box, or a bomb — each with its own sound effect (except the empty box, since it's empty). The box also squishes down and springs back every time you click it, for a little extra feedback.
