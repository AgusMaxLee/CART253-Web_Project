# SHOOTING SIMULATOR

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/arrays-prototype/shooting-simulator/)

## Description

> A simple 3D firing range built with p5's WEBGL mode. Click into the canvas to lock your mouse and look around like a first person shooter, then click again to shoot. A bunch of targets spawn randomly on the back wall, each click plays a shoot sound, and landing a hit pops the target and plays a hit sound.
