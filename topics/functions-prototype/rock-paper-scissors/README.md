# ROCK PAPER SCISSORS

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/functions-prototype/rock-paper-scissors/)

## Description

> Classic rock paper scissors against the computer, which always picks randomly. Click to start, pick your move, and see what the computer picked and who won. Wins and losses get tracked in the corner so you can keep playing rounds and see how you're doing.
>
> Built around functions: `getComputerChoice()` and `determineWinner()` both take input and return a result, `getImageForChoice()` turns a choice name back into the right image, and `isMouseOverButton()` handles the click detection for all three buttons without repeating the same check three times.
