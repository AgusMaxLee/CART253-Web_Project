# MALL JANITOR SIMULATOR

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/functions-prototype/prototype-2/)

## Description

> You're a mall janitor. Move with the arrow keys to pick up trash scattered around the mall while dodging the people walking by - bump into one and you're fired. The game over screen shows how much trash you managed to collect before getting caught.
>
> Built around reusable functions: `createPerson()` and `createTrash()` return freshly generated data, and the same `isColliding()` function checks both trash pickups and people collisions.
