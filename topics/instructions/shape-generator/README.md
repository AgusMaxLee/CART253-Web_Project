# SHAPE GENERATOR

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/instructions/shape-generator/)

## Description

> An abstract 3D scene of random shapes (boxes, spheres, cones, and torus shapes). Each time the page loads, a brand new set of shapes is generated: random positions. Some shapes spin, some float up and down, some do both, and some stay still.

## Attribution

> - This project uses [p5.js](https://p5js.org) and its WEBGL 3D renderer.
> - All shapes are original, drawn using p5's basic 3D drawing functions (`box`, `sphere`, `cone`, `torus`).
