# ROBOT HEAD

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/instructions/robot/)

## Description

> A 3D robot head with a simple face (two eyes and a mouth) that turns to follow your mouse. Move your mouse left/right and up/down over the canvas to make the head look around.

## Attribution

> - This project uses [p5.js](https://p5js.org) and its WEBGL 3D renderer.
> - All shapes are original, drawn using p5's basic 3D drawing functions (`box`, `sphere`).
