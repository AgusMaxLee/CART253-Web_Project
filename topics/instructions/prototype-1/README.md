# ROCKET LAUNCH

Agustin Maximo Lee

[View this project online](https://agusmaxlee.github.io/CART253-Web_Project/topics/instructions/prototype-1/)

## Description

> A simple animated scene of a rocket launching off the ground into a starry night sky. The rocket rises steadily at first, then accelerates and its flame grows once it passes a certain height. No interaction needed — just watch it launch.
